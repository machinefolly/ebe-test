# Playbooks

Each playbook is a self-contained guide for a common task. Follow the steps in order. If a step fails, check the Troubleshooting section before proceeding.

| Playbook | What it solves |
| --- | --- |
| [fork_and_rename.md](fork_and_rename.md) | Fork this repo and make it your own |
| [run_and_debug.md](run_and_debug.md) | Build and run your app, debug issues |
| [add_platform_target.md](add_platform_target.md) | Add a new OS/arch to the build matrix |
| [add_build_flag.md](add_build_flag.md) | Add a Go build tag to the pipeline |
| [wire_ci.md](wire_ci.md) | Set up GitHub Actions for cross-platform builds |
| [pin_or_bump_ebitengine.md](pin_or_bump_ebitengine.md) | Update the Ebitengine dependency |
